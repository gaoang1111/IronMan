# 研究综述：同源模型分化与自回归压缩记忆

> **项目代号**: IronCell / SoulBone
> **基座模型**: Llama 3.1 8B
> **核心范式**: Homologous Model Differentiation（同源模型分化）

---

## 1. 问题的提出

### 1.1 当前 AI 的根本局限：参数即状态机

当前所有 AI 架构——无论 Transformer、Mamba 还是其他变体——本质上都是一种 **预建的状态机**：

- **训练阶段**：用海量数据在参数空间里刻出一条条"高维路径"。例如，"我今天出门，外面下雨" 这样的训练数据，会让模型在高维空间中建立从"出门+下雨"到"拿把伞"的路径映射。
- **推理阶段**：用当前场景的信息作为 query，在预刻好的状态机里匹配路径，牵出一系列 answer。
- **根本局限**：参数是固定的、不可扩张的。不同的架构创新（attention、MoE、SSM 等）本质上只是让高维信息的抓取变得更高效，但没有改变"参数 = 能力上限"这个事实。

### 1.2 后训练的局限性

后训练（fine-tuning、RLHF 等）可以在一定程度上改变状态机的局部状态，但这是有很大局限性的：
- 它只是在已有的参数空间里重新调整权重分配
- 不能真正"长出新能力"
- 存在灾难性遗忘的风险
- 模型的知识容量有物理上限

### 1.3 核心问题

**当一个模型训好之后，如果你想要进行信息/能力的扩张，新增的参数从哪里来？如何确保新参数和原有参数能协同工作？**

## 2. 生物学启发：干细胞分裂与分化

### 2.1 人类记忆的扩展机制

人在碰到未知问题或者场景的时候，可以通过新的脑细胞之间建立突触去进行新的记忆。这种能力是 AI 目前不具备的——AI 的"记忆"固化在参数中，无法动态扩展。

### 2.2 干细胞的分裂与分化

生物体的一个优雅设计是 **干细胞分化**：
- **干细胞** 具有基础的、未分化的能力
- 需要运动时 → 分化为肌肉细胞
- 需要思考时 → 分化为脑细胞
- 需要免疫时 → 分化为免疫细胞

关键在于：由于整个人体都是由干细胞分裂分化而来的，**不会有排异反应**。所有分化后的细胞共享相同的基因组（参数基础），只是表达了不同的功能。

### 2.3 映射到 AI 系统

这个生物学直觉可以映射到模型设计：
- **基座模型 = 干细胞**：一个训好的、具有基础续写能力的 LLM（如 Llama 3.1 8B）
- **功能分化**：从同一个 checkpoint 克隆出多个副本，训练它们分化出不同的专门功能
- **无排异反应**：因为所有分化后的模型共享相同的预训练权重起点，它们的表示空间天然对齐——tokenizer 一致、embedding 层一致、层间语义结构共享

## 3. 核心方法：同源模型分化（Homologous Model Differentiation）

### 3.1 方法概述

取一个已经训好的基座模型（Llama 3.1 8B），克隆两份，让它们分化出不同功能：

| 组件 | 角色 | 来源 |
|------|------|------|
| **Compressor** | 压缩器/摘要器：读取文本 chunk，提取压缩表示 | Llama 3.1 8B clone |
| **Generator** | 生成器：使用压缩记忆进行续写生成 | Llama 3.1 8B clone |
| **Javis** | 桥接模块：cross-attention 提取 + 深层 KV 注入 | 新增可训练模块 |

### 3.2 同源的核心价值

两个模型从同一个 checkpoint 出发，最大的优势是 **前置相似性**：
- Tokenizer 完全一致——相同的词汇表和分词方式
- Embedding 层一致——相同的 token 到向量的映射
- 层间语义结构共享——类似 Llama 前几层关注局部信息、后面层融合全局信息的认知结构
- 这使得 Javis 桥接模块可以非常轻量，只需要学习"如何压缩"而不需要学习"如何对齐两个不同模型的表示空间"

### 3.3 灵感来源

- **Embedding 模型**：用一个向量来表示一个高维空间的状态/映射，实现一一对应。这说明将丰富的语义信息压缩到一个向量中是可行的。
- **H2O (Heavy Hitter Oracle) 等 KV 压缩**：KV cache 可以被大幅压缩而不损失太多信息，但 H2O 是启发式的、非学习型的。IronCell 想要用学习型的方式实现压缩。
- **跨模型 ResNet**：Deep KV injection 的灵感来源于残差连接的跨模型版本，让压缩信息能直接到达生成器的深层。

### 3.4 当前验证场景：自回归压缩记忆

压缩记忆是"同源分化"范式的 **第一个验证场景**：
- 实现 8:1 压缩率（16 tokens → 2 vectors）
- 在 Staircase Mask 下进行流式生成验证
- 通过 `<eoc>` token 预测验证压缩信息的有效性
- 目标不仅仅是做一个好的 KV 压缩方案，更重要的是验证 **同源模型可以通过分化来实现功能扩张**

## 4. 与已有工作的关系

### 4.1 对比表

| 维度 | Gisting / Soft Prompt | AutoCompressor / ICAE | H2O / KV Eviction | **IronCell** |
|------|----------------------|----------------------|-------------------|-------------|
| **压缩器** | 同模型内部，特殊 token 做 soft prompt | 自编码压缩，单模型 | 启发式策略，非学习型 | 独立的同源模型，专门分化 |
| **注入层** | 仅输入层 | 仅输入层或最后几层 | N/A（直接丢弃 KV） | Deep KV：多层残差注入 |
| **理论动机** | 工程优化 | 压缩表示学习 | 推理效率 | 生物学启发：干细胞分化 |
| **模型关系** | 单模型 | 单模型（encoder=decoder） | 单模型 | 双模型，同源分化 |
| **可扩展性** | 受限于单模型能力 | 受限于单模型能力 | 无学习能力 | 理论上可继续分化更多功能模块 |

### 4.2 IronCell 的独特贡献

1. **范式层面**：提出"同源模型分化"作为模型能力扩张的新思路，而非仅仅是一个压缩方案
2. **架构层面**：Deep KV Injection——压缩信息残差注入到生成器的多个 Transformer 层，而非仅在输入层
3. **训练策略**：Staircase Mask 强制模型依赖压缩信息 + 多阶段冻结策略 + `<eoc>` 预测防止信息坍缩
4. **实验发现**：Tail Bias 现象的发现与利用、层间注入系数的自发分化等

## 5. 术语表

| 术语 | 含义 |
|------|------|
| **同源模型分化** (Homologous Model Differentiation) | 从同一个预训练 checkpoint 克隆并分化出不同功能的模型 |
| **Compressor** | 压缩器，读取文本 chunk 并提取压缩表示 |
| **Generator** | 生成器，使用压缩记忆进行续写 |
| **Javis** | 跨模型 cross-attention 桥接模块，负责压缩提取和深层 KV 投影 |
| **Deep KV Injection** | 将压缩信息残差注入到生成器多个 Transformer 层的 KV 中 |
| **Zipper Layout** | 拉链式序列布局：压缩向量与 raw token 交替排列 |
| **Staircase Mask** | 阶梯式注意力遮罩：限制每个 chunk 只能看到前置压缩信息 |
| **Tail Bias** | 自回归模型中最后位置 token 注意力权重偏高的现象 |
| **Delta-Q** | 内容自适应的 query 偏置机制：q = q_base + delta_q(chunk_mean) |
| **Layer Gates** | 每层的可学习标量，控制 Deep KV 注入强度 |
